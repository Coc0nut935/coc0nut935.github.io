# 力扣刷题-[94. 二叉树的中序遍历](https://leetcode.cn/problems/binary-tree-inorder-traversal/)

## 题目：

给定一个二叉树的根节点 `root` ，返回 *它的 **中序** 遍历* 。

**示例 1：**

![img](https://assets.leetcode.com/uploads/2020/09/15/inorder_1.jpg)

```
输入：root = [1,null,2,3]
输出：[1,3,2]
```

## 题解：

中序遍历遵循 **“左子树 — 根节点 — 右子树”** 的访问顺序。首先判断当前节点是否为空，若为空则直接返回（递归终止条件）；否则，递归地遍历左子树（`dfs(root.left, ans)`），然后将当前节点的值加入结果列表（`ans.add(root.val)`），最后递归地遍历右子树（`dfs(root.right, ans)`）。通过这种自底向上的递归调用，可以保证所有左子树节点在根节点之前被访问，所有右子树节点在根节点之后被访问，从而得到完整的中序序列。

## 代码：

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> ans = new ArrayList<>();
        dfs(root,ans);
        return ans;
    }
    private void dfs(TreeNode root,List<Integer> ans){
        if(root == null){
            return;
        }
        dfs(root.left,ans);
        ans.add(root.val);
        dfs(root.right,ans);
    }
}
```

# 力扣刷题-[226. 翻转二叉树](https://leetcode.cn/problems/invert-binary-tree/)

## 题目：

给你一棵二叉树的根节点 `root` ，翻转这棵二叉树，并返回其根节点。

**示例 1：**

![img](https://assets.leetcode.com/uploads/2021/03/14/invert1-tree.jpg)

```
输入：root = [4,2,7,1,3,6,9]
输出：[4,7,2,9,6,3,1]
```

## 题解：

翻转二叉树的核心在于**自底向上地交换每个节点的左右子树**。递归地处理当前节点的左子树和右子树，分别得到翻转后的左子节点和右子节点，然后将当前节点的左指针指向翻转后的右子树，右指针指向翻转后的左子树，从而完成当前层级的镜像交换。这个过程从叶子节点开始逐步向上回溯，直到根节点为止，整棵树的所有分支都被完全反转。

## 代码：

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public TreeNode invertTree(TreeNode root) {
        if(root == null){
            return null;
        }
        TreeNode left = invertTree(root.left);
        TreeNode right = invertTree(root.right);
        root.left = right;
        root.right = left;
        return root;
    }
}
```

# 力扣刷题-[98. 验证二叉搜索树](https://leetcode.cn/problems/validate-binary-search-tree/)

## 题目：

给你一个二叉树的根节点 `root` ，判断其是否是一个有效的二叉搜索树。

**有效** 二叉搜索树定义如下：

- 节点的左子树只包含 **严格小于** 当前节点的数。
- 节点的右子树只包含 **严格大于** 当前节点的数。
- 所有左子树和右子树自身必须也是二叉搜索树。

**示例 1：**

![img](https://assets.leetcode.com/uploads/2020/12/01/tree1.jpg)

```
输入：root = [2,1,3]
输出：true
```

## 题解：

我们采用递归进行中序遍历（左-根-右），并用一个全局变量 `pre` 记录前一个访问节点的值，初始化为 `Long.MIN_VALUE`。在遍历过程中，首先递归检查左子树是否为 BST，若不是则提前返回 `false`；然后比较当前节点的值是否 **严格大于** `pre`，若小于等于则违反 BST 定义，返回 `false`；若通过则更新 `pre` 为当前值，最后递归检查右子树。

## 代码：

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private long pre = Long.MIN_VALUE;
    public boolean isValidBST(TreeNode root) {
        if(root == null){
            return true;
        }
        //递归左子树
        if(isValidBST(root.left) == false){
            return false;
        }
        //判断当前的根节点是否大于上一个数
        if(root.val <= pre){
            return false;
        }
        pre = root.val;
        //递归右子树
        return isValidBST(root.right);
    }
}
```
