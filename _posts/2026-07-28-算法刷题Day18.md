# 力扣刷题-[146. LRU 缓存](https://leetcode.cn/problems/lru-cache/)

## 题目：

请你设计并实现一个满足 [LRU (最近最少使用) 缓存](https://baike.baidu.com/item/LRU) 约束的数据结构。

实现 `LRUCache` 类：

- `LRUCache(int capacity)` 以 **正整数** 作为容量 `capacity` 初始化 LRU 缓存
- `int get(int key)` 如果关键字 `key` 存在于缓存中，则返回关键字的值，否则返回 `-1` 。
- `void put(int key, int value)` 如果关键字 `key` 已经存在，则变更其数据值 `value` ；如果不存在，则向缓存中插入该组 `key-value` 。如果插入操作导致关键字数量超过 `capacity` ，则应该 **逐出** 最久未使用的关键字。

函数 `get` 和 `put` 必须以 `O(1)` 的平均时间复杂度运行。

**示例：**

```
输入
["LRUCache", "put", "put", "get", "put", "get", "put", "get", "get", "get"]
[[2], [1, 1], [2, 2], [1], [3, 3], [2], [4, 4], [1], [3], [4]]
输出
[null, null, null, 1, null, -1, null, -1, 3, 4]
```

## 题解：

### 使用标准库：

如果是使用标准库的话，我们只需在构造时指定 `accessOrder=true`，即可让 `get` 和 `put` 操作自动将访问过的键值对移动到链表尾部（表示最新使用），而头部则自然沉淀着最久未使用的元素。在 `get` 方法中，先尝试移除并重新插入来刷新访问顺序；在 `put` 时，若 key 已存在则覆盖并更新顺序，若不存在且缓存已满，则直接移除迭代器的第一个元素（即最近最少使用的键），再插入新值。

### 手写双向链表：

需要定义一个虚拟头节点 `dummy` 作为哨兵，它的 `next` 指向最近使用的节点，`pre` 指向最久未使用的节点。**get 操作**通过哈希表获取节点后，先将其从链表中移除，再重新插入到 `dummy` 之后，以此刷新该节点的访问时间；**put 操作**同样先尝试获取节点，若存在则更新值并刷新位置，若不存在则判断缓存是否已满（通过 `keyToNode.size() >= capacity`），若满则移除 `dummy.pre`（最久未使用节点）并删除哈希表中的对应条目，最后创建新节点并插入链表头部。整个

手写双向链表会比使用标准库多写几个方法

| 多写的内容          | 对应的标准库部分                        | 代码中的方法                                      |
| :------------------ | :-------------------------------------- | :------------------------------------------------ |
| **1. 定义节点类**   | `LinkedHashMap` 内部的 `Entry` 类       | `static class Node { key, value, prev, next }`    |
| **2. 哨兵初始化**   | 标准库链表构造时的空头/空尾             | `dummy.prev = dummy; dummy.next = dummy;`         |
| **3. 原子删除操作** | 标准库 `LinkedList` 的 `unlink` 方法    | `private void remove(Node node)`（改前后指针）    |
| **4. 原子头插操作** | 标准库 `LinkedList` 的 `linkFirst` 方法 | `private void pushFront(Node node)`（改前后指针） |

```java
//手写双向链表
class LRUCache {
    private static class Node{
        int key;
        int value;
        Node pre;
        Node next;
        Node(int k, int v){
            key = k;
            value = v;
        }
    }
    private final int capacity;
    private final Node dummy = new Node(0,0);
    //用于查找双向链表中的具体节点对象。
    private final Map<Integer,Node> keyToNode = new HashMap<>();

    public LRUCache(int capacity) {
        this.capacity = capacity;
        dummy.pre = dummy;
        dummy.next = dummy;
    }
    
    public int get(int key) {
        //已经将通过删除key来判断是否存在封装到getNode方法中
        Node node = getNode(key);
        return node != null ? node.value : -1;
    }
    
    public void put(int key, int value) {
        Node node = getNode(key);
        //node不为空就说明存在;
        if(node != null){
            node.value = value;
            return;
        }
        //不存在就重新加入-满了就删除最久未使用节点，没满就直接加入
        if(keyToNode.size() >= capacity){
            Node eldestNode = dummy.pre;
            keyToNode.remove(eldestNode.key);
            remove(eldestNode); 
        }
        // 创建新节点
        Node newNode = new Node(key, value);
        keyToNode.put(key, newNode);
        putFront(newNode);
    }

    //getNode
    private Node getNode(int key){
        //不存在就返回null
        if(!keyToNode.containsKey(key)){
            return null;
        }
        Node node = keyToNode.get(key);
        //删除节点
        remove(node);
        //添加节点
        putFront(node);
        return node;
    }

    //删除节点
    private void remove(Node node){
        node.pre.next = node.next;
        node.next.pre = node.pre;
    }

    //将节点添加到头部
    private void putFront(Node node){
        //借助哨兵节点将新节点添加到头部
        node.pre = dummy;
        node.next = dummy.next;
        node.pre.next = node;
        node.next.pre = node;
    }
}

/**
 * Your LRUCache object will be instantiated and called as such:
 * LRUCache obj = new LRUCache(capacity);
 * int param_1 = obj.get(key);
 * obj.put(key,value);
 */
```
