# 力扣刷题-[78. 子集](https://leetcode.cn/problems/subsets/)

## 题目：

给你一个整数数组 `nums` ，数组中的元素 **互不相同** 。返回该数组所有可能的子集（幂集）。

解集 **不能** 包含重复的子集。你可以按 **任意顺序** 返回解集。

**示例 1：**

```
输入：nums = [1,2,3]
输出：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

## 题解：

今天学习的思路是**0x3f**的思路，也就是通过**枚举每个元素“选”或“不选”的所有组合**，形成一棵深度为 `n` 的决策树。我们采用回溯（深度优先搜索）遍历这棵树：从数组第一个元素开始，每次递归调用都面临两个分支——**不选当前元素**（直接进入下一个元素的决策）和**选当前元素**（将当前元素加入临时列表 `path`，然后进入下一个元素的决策）。当处理完所有 `n` 个元素时（即到达叶子节点），当前的 `path` 就代表一个完整的子集，我们将其**拷贝并加入结果集**。递归返回后，需要撤销上一步的选择（`path.removeLast()`），以便尝试其他分支。

## 代码：

```java
class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> ans = new ArrayList<>();
        List<Integer> path = new ArrayList<>();
        backTracking(0,nums,path,ans);
        return ans;
    }
    public void backTracking(int i,int[] nums,List<Integer> path,List<List<Integer>> ans){
        if(i == nums.length){
            ans.add(new ArrayList<>(path));
            return;
        }
        //重点：不是在“某个条件满足时”才选，而是“无论什么情况，都要把‘选’和‘不选’这两种情况全部尝试一遍”。
        //不选
        backTracking(i + 1,nums,path,ans);
        //选
        path.add(nums[i]);
        backTracking(i + 1,nums,path,ans);
        //回溯(删除最后一个)
        path.removeLast();

    }
}
```
