# 力扣刷题-[148. 排序链表](https://leetcode.cn/problems/sort-list/)

## 题目：

给你链表的头结点 `head` ，请将其按 **升序** 排列并返回 **排序后的链表** 。

**示例 1：**

![img](https://assets.leetcode.com/uploads/2020/09/14/sort_list_1.jpg)

```
输入：head = [4,2,1,3]
输出：[1,2,3,4]
```

## 题解：

这道题我是用的是自顶向下，也就是将链表一分为二，分别排序后再合并。首先，通过**快慢指针**找到链表的中间节点，并切断前后两部分的联系，将链表拆分成两个独立的子链表；然后，递归地对这两个子链表分别进行排序（递归终止条件是链表为空或只有一个节点，此时已天然有序）；最后，使用**双指针合并**两个有序子链表，将它们合并为一个有序的完整链表。

## 代码：

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode sortList(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }
        //找到中点，分割链表
        ListNode mid = middleNode(head);
        ListNode left = head;
        ListNode right = mid;
        //递归排序左右两部分
        left = sortList(left);
        right = sortList(right);
        //合并两个有序链表
        return mergeList(left, right);
    }

    //快慢指针，找到中间点,将链表分为前后两段
    private ListNode middleNode(ListNode head){
        ListNode fast = head;
        ListNode slow = head;
        ListNode pre = head;
        while(fast != null&&fast.next != null){
            pre = slow;
            slow = slow.next;
            fast = fast.next.next;
        }
        pre.next = null;
        return slow;
    }

    //链表合并
    private ListNode mergeList(ListNode list1,ListNode list2){
        //设置哨兵节点
        ListNode dummy = new ListNode();
        ListNode curnode = dummy;
        while(list1 != null&&list2 != null){
            if(list1.val < list2.val){
                curnode.next = list1;
                list1 = list1.next;;
            }
            else {
                curnode.next = list2;
                list2 = list2.next;
            }
            curnode = curnode.next;
        }
        curnode.next = list1 != null ? list1 : list2;
        return dummy.next;
    }

}
```
