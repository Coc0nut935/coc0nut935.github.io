# 力扣刷题-[236. 二叉树的最近公共祖先](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/)

## 题目：

给定一个二叉树, 找到该树中两个指定节点的最近公共祖先。

[百度百科](https://baike.baidu.com/item/最近公共祖先/8918834?fr=aladdin)中最近公共祖先的定义为：“对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（**一个节点也可以是它自己的祖先**）。”

**示例 1：**

![img](https://assets.leetcode.com/uploads/2018/12/14/binarytree.png)

```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
输出：3
解释：节点 5 和节点 1 的最近公共祖先是节点 3 。
```

## 题解：

通过**自底向上地传递“找到的节点信息”**。首先需要写出递归的终止条件：若当前节点为空，或当前节点就是 `p` 或 `q`，则直接返回当前节点（因为找到目标节点后无需再向下遍历）。随后，我们在左子树和右子树中分别递归查找，得到返回值 `left` 和 `right`。如果 `left` 和 `right` 均非空，说明 `p` 和 `q` 分别位于当前节点的左右两侧，因此当前节点就是它们的最近公共祖先，直接返回 `root`。如果只有一侧非空（例如 `left` 非空而 `right` 为空），则说明两个目标节点都在左子树中，且左子树的返回值已经是它们的 LCA，直接向上传递即可；同理右子树也如此。如果两侧均为空，则当前子树中不包含目标节点，返回 `null`。

## 代码：

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode(int x) { val = x; }
 * }
 */
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if(root == q || root == p || root == null){
            return root;
        }
        TreeNode left = lowestCommonAncestor(root.left,p,q);
        TreeNode right = lowestCommonAncestor(root.right,p,q);
        if(left != null && right != null){
            return root;
        }

        if(left != null){
            return left;
        }
        else return right;
    }
}
```
