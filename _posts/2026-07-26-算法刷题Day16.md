# 力扣刷题-[[24. 两两交换链表中的节点](https://leetcode.cn/problems/swap-nodes-in-pairs/)](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/)

## 题目：

给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部的值的情况下完成本题（即，只能进行节点交换）。

**示例 1：**

![img](https://assets.leetcode.com/uploads/2020/10/03/swap_ex1.jpg)

```
输入：head = [1,2,3,4]
输出：[2,1,4,3]
```

## 题解：

可以将**链表拆分为“当前两节点”和“剩余子链表”两个部分，先处理子问题，再连接当前部分**。在这段递归代码中，我们首先处理边界条件（链表为空或只有一个节点，无需交换），然后保存前两个节点 `node1` 和 `node2`，以及后续子链表的头节点 `node3`。接下来，我们**递归地交换 `node3` 及其之后的节点**，得到已经处理好的子链表的头节点（即原第三个节点翻转后的新头），并将其作为 `node1` 的 `next` 指向。最后，让 `node2.next` 指向 `node1`，完成当前两节点的交换，并返回 `node2` 作为整个链表的新头节点。整个递归过程自底向上地构建结果：先处理后面的部分，确保交换后的子链表已经连好，再回过头来处理前两个节点。

## 代码：

```java
class Solution {
    public ListNode swapPairs(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }

        ListNode node1 = head;
        ListNode node2 = head.next;
        ListNode node3 = node2.next;

        //1 指向递归返回的链表头
        node1.next = swapPairs(node3);
        node2.next = node1; // 2 指向 1

        return node2; //返回交换后的链表头节点
    }
}
```
