# 力扣刷题-[138. 随机链表的复制](https://leetcode.cn/problems/copy-list-with-random-pointer/)

## 题目：

给你一个长度为 `n` 的链表，每个节点包含一个额外增加的随机指针 `random` ，该指针可以指向链表中的任何节点或空节点。

构造这个链表的 **[深拷贝](https://baike.baidu.com/item/深拷贝/22785317?fr=aladdin)**。 深拷贝应该正好由 `n` 个 **全新** 节点组成，其中每个新节点的值都设为其对应的原节点的值。新节点的 `next` 指针和 `random` 指针也都应指向复制链表中的新节点，并使原链表和复制链表中的这些指针能够表示相同的链表状态。**复制链表中的指针都不应指向原链表中的节点** 。

例如，如果原链表中有 `X` 和 `Y` 两个节点，其中 `X.random --> Y` 。那么在复制链表中对应的两个节点 `x` 和 `y` ，同样有 `x.random --> y` 。

返回复制链表的头节点。

用一个由 `n` 个节点组成的链表来表示输入/输出中的链表。每个节点用一个 `[val, random_index]` 表示：

- `val`：一个表示 `Node.val` 的整数。
- `random_index`：随机指针指向的节点索引（范围从 `0` 到 `n-1`）；如果不指向任何节点，则为 `null` 。

你的代码 **只** 接受原链表的头节点 `head` 作为传入参数。 

**示例 1：**

![img](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2020/01/09/e1.png)

```
输入：head = [[7,null],[13,0],[11,4],[10,2],[1,0]]
输出：[[7,null],[13,0],[11,4],[10,2],[1,0]]
```

## 题解：

### 哈希表：

我们首先遍历原链表，为每个节点创建一个值相同的新节点，并将原节点作为键、新节点作为值存入哈希表中；然后再次遍历原链表，利用哈希表快速查找，将每个新节点的 `next` 和 `random` 指针分别指向其对应原节点的 `next` 和 `random` 所对应的新节点。这样，我们通过两次线性遍历，在 O(n) 时间和 O(n) 空间内完成了深拷贝。

### **原地复制 + 拆分**：

这个方法是看到0x3f的题解，看完之后感觉真的牛逼，他的思路主要分为三步

1. **插入复制节点**：遍历原链表，在每个原节点后面紧挨着插入一个它的复制节点（只复制 `val`，暂不处理 `random`）。这样原链表和复制节点交替排列，形成“原 → 复 → 原 → 复”的交错链表。
2. **设置 random 指针**：再次遍历这个交错链表，对于每个原节点 `cur`，它的复制节点就是 `cur.next`。如果 `cur.random` 存在，那么 `cur.next.random` 就应该指向 `cur.random.next`（因为 `cur.random` 是原节点，它的下一个就是对应的复制节点）。这一步利用了插入位置的关系，直接 O(1) 定位到目标复制节点。
3. **拆分链表**：最后遍历交错链表，把原节点和复制节点分离。用虚拟头节点 `dummy` 和尾指针 `tail` 依次串起复制节点，同时恢复原节点的 `next` 指向（即 `cur.next = copy.next`），还原原链表结构。

```java
// Definition for a Node.
class Node {
    int val;
    Node next;
    Node random;

    public Node(int val) {
        this.val = val;
        this.next = null;
        this.random = null;
    }
}
*/

class Solution {
    public Node copyRandomList(Node head) {
        // //创建hash表
        // Map<Node,Node> map = new HashMap<>();
        // Node cur = head;
        // //第一次遍历，用于复制值
        // while(cur != null){
        //     //为每个原节点创建一个值相同的新节点
        //     map.put(cur,new Node(cur.val));
        //     cur = cur.next;
        // }

        // //第二次遍历，设置复制节点的 next 和 random 指针
        // cur = head;
        // while(cur != null){
        //     //获取当前节点对应的新节点
        //     Node copy = map.get(cur);
        //     copy.next = map.get(cur.next);
        //     copy.random = map.get(cur.random);
        //     cur = cur.next;
        // }
        // return map.get(head);
        
        // ---------- 第一步：插入复制节点 ----------
        // 遍历原链表，在每个节点后面插入一个复制节点
        // 注意：cur = cur.next.next 是因为插入新节点后，cur.next 已经变成了新节点，
        // 所以下一次应该跳到原节点的下一个（即新节点的下一个，也就是 cur.next.next）
        for (Node cur = head; cur != null; cur = cur.next.next) {
            // 创建复制节点，值同 cur，next 指向 cur 原来的下一个
            cur.next = new Node(cur.val, cur.next);
        }

        // ---------- 第二步：设置复制节点的 random ----------
        // 再次遍历交错链表，此时每个原节点后面紧跟着它的复制节点
        for (Node cur = head; cur != null; cur = cur.next.next) {
            // 如果原节点的 random 指针不为空
            if (cur.random != null) {
                // cur.next 是复制节点，它的 random 应该指向 cur.random 的复制节点
                // cur.random 是原节点，它的下一个（cur.random.next）就是对应的复制节点
                cur.next.random = cur.random.next;
            }
        }

        // ---------- 第三步：拆分交错链表，分离出复制链表 ----------
        Node dummy = new Node(0);  // 虚拟头节点，方便构建复制链表
        Node tail = dummy;         // tail 指向复制链表的尾节点
        // 再次遍历原链表，这次每次只走一步（cur = cur.next），因为要跳过复制节点
        // 注意：cur 移动的是原链表，而 tail 移动的是复制链表
        for (Node cur = head; cur != null; cur = cur.next, tail = tail.next) {
            Node copy = cur.next;   // copy 是当前原节点后面的复制节点
            tail.next = copy;       // 将 copy 接到复制链表的尾部
            cur.next = copy.next;   // 恢复原节点的 next 指向（跳过复制节点，指向原来的下一个原节点）
        }

        return dummy.next; // 复制链表的头节点
    }
}
```
