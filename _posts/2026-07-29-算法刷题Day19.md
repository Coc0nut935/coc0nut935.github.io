# 力扣刷题-[104. 二叉树的最大深度](https://leetcode.cn/problems/maximum-depth-of-binary-tree/)

## 题目：

给定一个二叉树 `root` ，返回其最大深度。

二叉树的 **最大深度** 是指从根节点到最远叶子节点的最长路径上的节点数。

**示例 1：**

![img](https://assets.leetcode.com/uploads/2020/11/26/tmp-tree.jpg)

 

```
输入：root = [3,9,20,null,null,15,7]
输出：3
```

## 题解：

这段递归代码是解决二叉树最大深度问题最经典的**深度优先搜索（DFS）后序遍历**解法，其核心思想是“分而治之”。我们首先定义递归的边界条件：如果当前节点为空，则返回深度为 0。否则，我们分别递归地计算左子树和右子树的最大深度，最后取两者中的较大值并加上 1（当前根节点所在的层数），即为以当前节点为根的子树的深度。

## 代码：

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public int maxDepth(TreeNode root) {
        if(root == null){
            return 0;
        }
        int leftdepth = maxDepth(root.left);
        int rightdepth = maxDepth(root.right);
        return Math.max(leftdepth,rightdepth) + 1;
    }
}
```

# 力扣刷题=[100. 相同的树](https://leetcode.cn/problems/same-tree/)

## 题目：

给你两棵二叉树的根节点 `p` 和 `q` ，编写一个函数来检验这两棵树是否相同。

如果两个树在结构上相同，并且节点具有相同的值，则认为它们是相同的。

**示例 1：**

![img](https://assets.leetcode.com/uploads/2020/12/20/ex1.jpg)

```
输入：p = [1,2,3], q = [1,2,3]
输出：true
```

## 题解：

我们从根节点开始，首先检查当前两个节点是否都为空——若是，则它们相等，返回 `true`；若仅有一个为空，则结构不同，返回 `false`；若两者都不为空，则比较它们的值是否相等，并递归地比较它们的左子树和右子树是否分别相同。这种“**先判空，再判值，后递归**”的策略，本质上是深度优先的前序遍历比较。

## 代码：

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public boolean isSameTree(TreeNode p, TreeNode q) {
        if(p == null && q == null){
            return true;
        }
        if(p == null || q == null){
            return false;
        }
        
        boolean ans = p.val == q.val && isSameTree(p.left,q.left) && isSameTree(p.right,q.right);
        return ans;
    }
}
```

# 力扣刷题-[101. 对称二叉树](https://leetcode.cn/problems/symmetric-tree/)

## 题目：

给你一个二叉树的根节点 `root` ， 检查它是否轴对称。

**示例 1：**

![img](https://pic.leetcode.cn/1698026966-JDYPDU-image.png)

```
输入：root = [1,2,2,3,4,4,3]
输出：true
```

## 题解：

将问题转化为比较根节点的左子树和右子树是否互为镜像。编写一个辅助函数，同时传入两个节点进行比较：若两个节点都为空则返回 `true`；若仅有一个为空则返回 `false`；若均非空，则先比较它们的值是否相等，再递归地比较 **左节点的左孩子 与 右节点的右孩子**（即两棵子树的外侧），以及 **左节点的右孩子 与 右节点的左孩子**（即两棵子树的内侧）。只有当所有对应位置的值都相等时，才确认整棵树对称。

## 代码：

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public boolean isSymmetric(TreeNode root) {
        return isSameTree(root.left,root.right);
    }

    private boolean isSameTree(TreeNode p,TreeNode q){
        if(p == null && q == null){
            return true;
        }
        if(p == null || q == null){
            return false;
        }
        boolean ans = p.val == q.val && isSameTree(p.left,q.right) && isSameTree(p.right,q.left);
        return ans;
    }
}
```

# 力扣刷题-[110. 平衡二叉树](https://leetcode.cn/problems/balanced-binary-tree/)

## 题目：

给定一个二叉树，判断它是否是 平衡二叉树 

**示例 1：**

![img](https://assets.leetcode.com/uploads/2020/10/06/balance_1.jpg)

```
输入：root = [3,9,20,null,null,15,7]
输出：true
```

## 题解：

我们定义递归函数 `getTreeHeight(root)`：若节点为空返回高度 0；否则递归获取左、右子树的高度。**关键步骤**是：在递归返回后，先检查左右子树高度是否为 `-1`（表示该子树已不平衡），若是则立即向上传播 `-1`，终止不必要的计算；若均未失衡，则比较两者高度差，若差值大于 1 则返回 `-1`，否则返回 `max(left, right) + 1` 作为当前子树高度。

## 代码：

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public boolean isBalanced(TreeNode root) {
        boolean ans = getTreeHeight(root) != -1;
        return ans;
    }

    private int getTreeHeight(TreeNode root){
        if(root == null){
            return 0;
        }
        int leftHeight = getTreeHeight(root.left);
        int rightHeight = getTreeHeight(root.right);
        if(leftHeight == -1 || rightHeight == -1 || Math.abs(leftHeight - rightHeight) > 1){
            return -1;
        }
        return Math.max(leftHeight,rightHeight) + 1;
    }
}
```

# 力扣刷题-[199. 二叉树的右视图](https://leetcode.cn/problems/binary-tree-right-side-view/)

## 题目：

给定一个二叉树的 **根节点** `root`，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

**示例 1：**

**输入：**root = [1,2,3,null,5,null,4]

**输出：**[1,3,4]

**解释：**

![img](https://assets.leetcode.com/uploads/2024/11/24/tmpd5jn43fs-1.png)

## 题解：

通过**优先遍历右子树，再遍历左子树**实现，并同时传递当前节点的深度 `depth`。同时维护一个答案列表 `ans`，它的长度表示已经记录到的层数。当递归到某个节点时，如果当前深度 `depth` 正好等于 `ans.size()`，说明这一层还没有节点被记录，而当前节点正是该层最右侧的节点（因为先右后左），于是将其值加入 `ans`。随后继续递归右子树和左子树，并传递深度 `depth + 1`。这样每一层只有最先被访问到的那个节点（即最右侧节点）才会被记录。

## 代码：

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> ans = new ArrayList<>();
        return dfs(root,0,ans);
    }
    private List<Integer> dfs(TreeNode root,int curDepth,List<Integer> ans){
        if(root == null){
            return ans;
        }
        //当当前深度与ans的长度一样时，那就说明被遮挡（首次出现）
        if(curDepth == ans.size()){
            ans.add(root.val);
        }
        //先递归右子树，再递归左子树
        dfs(root.right,curDepth + 1,ans);
        dfs(root.left,curDepth + 1,ans);
        return ans;
    }
}
```
