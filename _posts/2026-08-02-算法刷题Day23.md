# 力扣刷题-[103. 二叉树的锯齿形层序遍历](https://leetcode.cn/problems/binary-tree-zigzag-level-order-traversal/)

## 题目：

给你二叉树的根节点 `root` ，返回其节点值的 **锯齿形层序遍历** 。（即先从左往右，再从右往左进行下一层遍历，以此类推，层与层之间交替进行）。

**示例 1：**

![img](https://assets.leetcode.com/uploads/2021/02/19/tree1.jpg)

```
输入：root = [3,9,20,null,null,15,7]
输出：[[3],[20,9],[15,7]]
```

## 题解：

锯齿形层序遍历跟昨天写的层序遍历本质上一样，但是需要在基数的时候进行反转。我们采用列表 `curNode` 存储当前层的所有节点，在每一轮中，遍历 `curNode` 收集节点值到 `vals`，同时将它们的非空左右子节点加入下一层列表 `nextNode`。随后，我们通过当前已记录层数 `ans.size()` 的奇偶性判断当前层是否需要反转——如果 `ans.size()` 为奇数（表示当前层是奇数层，从 0 开始计数，即第 1、3、5... 层），则反转 `vals`，再添加到结果列表；否则直接添加。

## 代码：

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
        List<List<Integer>> ans = new ArrayList<>();
        List<TreeNode> curNode = new ArrayList<>();
        if(root == null){
            return ans;
        }
        curNode.add(root);
        while(!curNode.isEmpty()){
            List<TreeNode> nextNode = new ArrayList<>();
            List<Integer> vals = new ArrayList<>();
            for(TreeNode node : curNode){
                vals.add(node.val);
                if(node.left != null){
                    nextNode.add(node.left);
                }
                if(node.right != null){
                    nextNode.add(node.right);
                }
            }
            curNode = nextNode;
            //为奇数就反转
            if(ans.size()%2 > 0){
                Collections.reverse(vals);
            }
            ans.add(vals);
        }
        return ans;
    }
}
```
