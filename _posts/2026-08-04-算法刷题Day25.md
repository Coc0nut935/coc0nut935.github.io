# 力扣刷题-[17. 电话号码的字母组合](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/)

## 题目：

给定一个仅包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。答案可以按 **任意顺序** 返回。

给出数字到字母的映射如下（与电话按键相同）。注意 1 不对应任何字母。

![img](https://pic.leetcode.cn/1752723054-mfIHZs-image.png)

**示例 1：**

```
输入：digits = "23"
输出：["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

## 题解：

通过 **回溯**可以解决这个问题。我们将数字到字母的映射关系预存为数组，然后递归地处理每个数字：当处理到某个数字时，遍历该数字对应的所有字母，将当前字母加入临时组合，并递归处理下一个数字；当递归到所有数字都已处理完成时，将当前临时组合加入结果集合。递归返回后需要撤销上一步的选择（即删除刚加入的字母），以保证尝试其他可能性时不会相互干扰。

我听了**代码随想录**的回溯的讲解，他说这种回溯的题目都是有固定的模板的，也就是“**选择 → 递归 → 撤销选择**”这样的模板。

## 代码：

```java
class Solution {
    List<String> ans = new ArrayList<>();

    public List<String> letterCombinations(String digits) {
        if(digits == null || digits.length() == 0){
            return ans;
        }
        String[] numString = {"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};
        backTracking(digits,numString,0);
        return ans;
    }

    StringBuilder temp = new StringBuilder();
    public void backTracking(String digits,String[] numString,int index){
        //边界条件
        if(index == digits.length()){
            ans.add(temp.toString());
            return;
        }
        //为了把字符类型的数字（如 '2'）转换成真正的整数（如 2），以便作为数组下标去查找对应的字母字符串。当执行 '2' - '0' 时，实际是 50 - 48，结果就是整数 2。
        int num = digits.charAt(index) - '0';
        //获取当前数字对应的字符串
        String str = numString[num];
        for(int i = 0;i < str.length();i++){
            //加入当前字母
            temp.append(str.charAt(i));
            backTracking(digits,numString,index + 1);
            //回溯(将末尾的元素弹出)，因为索引从0开始，所以要减一
            temp.deleteCharAt(temp.length() - 1);
        }
    }
}
```
