# 力扣刷题-[513. 找树左下角的值](https://leetcode.cn/problems/find-bottom-left-tree-value/)

## 题目：

给定一个二叉树的 **根节点** `root`，请找出该二叉树的 **最底层 最左边** 节点的值。

假设二叉树中至少有一个节点。

**示例 1:**

![img](https://assets.leetcode.com/uploads/2020/12/14/tree1.jpg)

```
输入: root = [2,1,3]
输出: 1
```

## 题解：

可以使用**层序遍历**，入队顺序为**先右后左**。我们从根节点开始，使用队列逐层处理节点。在每一层中，先弹出队首节点，然后将它的右子节点入队，再将左子节点入队（如果存在）。这样，在每一层内部，右边节点会先被访问，左边节点会后被访问；但层序遍历整体是从上到下逐层推进的。因此，当队列全部处理完时，**最后被弹出的节点一定是最底层（最后一层）且在该层中最靠左的节点**。

## 代码：

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public int findBottomLeftValue(TreeNode root) {
        TreeNode node = root;
        Queue<TreeNode> q = new ArrayDeque<>();
        q.add(root);
        while(q.isEmpty() == false){
            //取出队首
            node = q.poll();
            //从右往左入队列
            if(node.right != null){
                q.add(node.right);
            }
            if(node.left != null){
                q.add(node.left);
            }
        }
        return node.val;
    }
}
```
